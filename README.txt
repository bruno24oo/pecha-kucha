TRIVIUM — PECHA KUCHA
=====================

Como utilizar:
1. Extraia a pasta do ZIP.
2. Abra index.html num navegador atualizado.
3. Clique em “Iniciar apresentação”.

Estrutura:
- index.html  — estrutura dos 20 slides
- style.css   — identidade visual e responsividade
- script.js   — temporizador, navegação e controlos
- images/     — 20 ilustrações SVG locais, uma por slide

Controlos:
- ← / → : slide anterior / seguinte
- Espaço : iniciar / pausar
- R : reiniciar
- F : ecrã inteiro
- Escape : sair do ecrã inteiro

Personalização:
As imagens estão em images/. Substitua qualquer SVG por uma imagem sua,
mantendo o mesmo nome de ficheiro, ou altere o caminho no array
TRIVIUM_SLIDES no index.html.

Nota:
O símbolo apresentado na abertura é um elemento gráfico provisório.
Substitua-o pelo logótipo oficial da TRIVIUM quando estiver disponível.
A apresentação usa fontes Marcellus e Manrope via Google Fonts; sem ligação
à internet, serão utilizadas fontes de sistema como alternativa.
